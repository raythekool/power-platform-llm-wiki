Example for a CE project on Azure DevOps

  • Code repository: name crm-solution, provider azure-devops, branch develop, local folder ../crm-solution.
  • Boards: organization contoso, project Sales.
  • Dataverse: solution SalesCore, prefix cts_.

Code not in git? Common in older F&O projects with the code in TFS. Use provider: tfvc with tf.exe (Visual Studio), the collection URL (e.g. https://tfs.contoso.local/tfs/DefaultCollection), the $/Project/Trunk/Main path and a local folder; on an F&O developer VM use the folder the workspace already maps. No tf.exe? Download the folder from the web portal (Repos → Files → Download as Zip) and use provider: local. The agent only reads TFVC (get, history), never checks in or out; without git, changes are found by file hashes and pages cite the changeset (fno@C1234:...).

Important: never write passwords, tokens or keys in the answers or in the configuration file. Access uses your account (Microsoft Entra ID, az login, pacx auth).

✅ Verify: for every repository the local folder exists (or will be cloned). For Dataverse, pacx auth ping replies.

Tutte le fonti sono facoltative. Il wizard le propone una per volta: rispondi Sì solo a quelle che hai.
