Why it mattersPerché serve

Documentation usually loses against the delivery pace.

La documentazione di solito perde contro il ritmo di delivery.

LLM Wiki attacks the four reasons why.

LLM Wiki affronta i quattro motivi.

🧭

Docs drift from reality

I documenti si disallineano

Code-first

Trust the code, question the document.

Fidati del codice, metti in dubbio il documento.

Requirement pages carry an ID, code pages declare what they implement. The lint tells you what is missing, the update flags what disagrees.

Le pagine dei requisiti hanno un ID, le pagine di codice dichiarano cosa implementano. Il lint dice cosa manca, l'update segnala cosa non coincide.

  • Primary source of truth for as-built behaviour: the code, not the document.
  • Fonte primaria dell'as-built: il codice, non il documento.
  • Gaps are flagged on both pages with evidence; nothing is silently rewritten.
  • Le differenze sono segnalate su entrambe le pagine con evidenza; nulla viene riscritto in silenzio.
  • Untraced components and requirements without implementation are listed by the lint.
  • Componenti non tracciati e requisiti senza implementazione sono elencati dal lint.

FAQ

Good questions.

Domande frequenti.

Do I need a personal access token?Serve un personal access token?

No. Azure DevOps uses Microsoft Entra ID sign-in through the MCP server, and publishing uses Git Credential Manager. CI runs use repository secrets.

No. Azure DevOps usa l'accesso Microsoft Entra ID tramite il server MCP e la pubblicazione usa Git Credential Manager. Le esecuzioni in CI usano i secret del repository.

Where does the wiki live?Dove vive la wiki?

In the project repository, under llm-wiki/, as plain Markdown. The published wiki is a converted copy.

Nel repository del progetto, in llm-wiki/, come Markdown semplice. La wiki pubblicata è una copia convertita.

What if people only use Azure DevOps or Copilot?E se le persone usano solo Azure DevOps o Copilot?

They read the published wiki, or ask it through Microsoft 365 Copilot / Copilot Studio connected to that wiki. VS Code is only needed by the people who maintain it.

Leggono la wiki pubblicata, oppure la interrogano tramite Microsoft 365 Copilot / Copilot Studio collegati alla wiki. VS Code serve solo a chi la mantiene.

Can the agent change certified pages?L'agente può modificare le pagine certificate?

No. New information is added as a "Pending updates" section for the page owner to accept or reject.

No. Le nuove informazioni vengono aggiunte come sezione "Pending updates" che l'owner della pagina accetta o rifiuta.

How do I keep costs under control?Come tengo sotto controllo i costi?

Only changed sources are processed, scripts replace LLM reading wherever possible, and each log entry records the volume processed.

Si elaborano solo le fonti cambiate, gli script sostituiscono la lettura dell'LLM dove possibile e ogni voce di log registra il volume elaborato.
